# MD. Toufiq Hossain — Portfolio

Personal portfolio website of **MD. Toufiq Hossain**, Urban Planner and Researcher based in Dhaka, Bangladesh.

The website presents professional experience, education, research publications, technical skills, certificates, and contact links.

## Live website

After enabling GitHub Pages, the site will be available at:

`https://YOUR-GITHUB-USERNAME.github.io/`

Replace `YOUR-GITHUB-USERNAME` with your GitHub username.

## Deploy with GitHub Pages

1. Create a new **public** GitHub repository named exactly `YOUR-GITHUB-USERNAME.github.io`.
2. Upload `index.html` and this `README.md` to the repository's root directory.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and the `/ (root)` folder, then click **Save**.
6. Wait for GitHub Pages to publish the site. Your portfolio will appear at the URL above.

You can also use any repository name and enable Pages for a project site; its URL will then include the repository name.

## Project structure

```text
.
├── index.html
└── README.md
```

The portfolio is a self-contained HTML page. Its styling, scripts, and visual assets are embedded in the HTML file, so no build command or package installation is required.

## Updating the portfolio

- Edit `index.html` to update text, links, publications, experience, or other content.
- Commit and push the changes to the `main` branch.
- GitHub Pages will publish the updated site automatically.

## Notes before publishing

- Check that your email address, phone number, and external profile links are the ones you want to make public.
- Review all publication metadata and dates for accuracy.
- The page loads web fonts from Google Fonts; if those fonts are unavailable, fallback fonts are defined.
