# MD. Toufiq Hossain Portfolio Website

This folder is ready to upload to a GitHub repository and publish with GitHub Pages.

## Files

- `toufiq.html` — main portfolio website file.
- `index.html` — GitHub Pages entry file that redirects visitors to `toufiq.html`.
- `.nojekyll` — prevents GitHub Pages/Jekyll processing issues.

## Upload to GitHub

1. Create a new GitHub repository.
2. Upload all files from this folder to the repository root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select your branch, usually `main`, and folder `/root`.
6. Save and open the published GitHub Pages link.

## Local Preview

Open `toufiq.html` in a browser.

Note: the embedded OpenStreetMap and Google Fonts require an internet connection.
